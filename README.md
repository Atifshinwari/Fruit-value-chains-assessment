# Fruit value chains assessment in Afghanistan

This repository contains the R code, aggregated analysis data, and Supplementary Material associated with the study:

**A holistic assessment of the horticultural fruit and nut value chains in Afghanistan: identifying key constraints and priority interventions**

The study assesses 13 fruit and nut value chains in Afghanistan using structured expert elicitation and a rule-based prioritization approach to identify key constraints and priority interventions.

## Repository contents

The repository includes:

- R scripts used for data preparation, analysis, summary statistics, and figure generation
- Aggregated quantitative and certification datasets used in the analyses
- Supplementary Material associated with the study
- Supporting question-label mapping used for figure presentation

## Supplementary Material

The Supplementary Material is available in the `supplementary` folder.

## Data availability

The aggregated datasets used for the publicly reproducible analyses are included in this repository. Expert-level responses and other restricted source data are not publicly available because of confidentiality and data-use restrictions.

## Software

The analyses were conducted in R. Required packages are specified in the individual scripts.
